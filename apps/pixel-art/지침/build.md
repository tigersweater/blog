# Build 담당 지침: 픽셀 아트 에디터

## 할 일
`apps/pixel-art/spec.md`(계획서)대로 픽셀 아트 에디터를 만든다. 계획서 **10번 "결정 사항"**이 최종 결정이다.

## 만들 파일 (이 4개만)
| 파일 | 내용 |
|---|---|
| `apps/pixel-art/index.html` | 화면 뼈대 (`<html lang="ko">`, viewport 메타, 제목 "픽셀 아트") |
| `apps/pixel-art/style.css` | 디자인, 체크무늬, 다크 모드(`prefers-color-scheme`), 휴대폰 배치 |
| `apps/pixel-art/app.js` | 칠하기·지우개·채우기·스포이드·되돌리기·격자선·PNG 저장·자동 저장 |
| `apps/pixel-art/preview.svg` | 블로그 카드용 미리보기 그림. 작은 도트 그림(예: 하트·버섯 같은 단순한 그림)이 그려진 16×16 판 + 팔레트 일부. 가로:세로 = 16:10 정도, 밝은 색 기준, 외부 글꼴 없이 |

## 지켜야 할 규칙
- HTML, CSS, JavaScript만. 프레임워크·외부 라이브러리·CDN·외부 글꼴 쓰지 않음
- `index.html`을 **더블클릭(file://)으로 열어도 동작**: `fetch`, `type="module"`, `import` 쓰지 않음. `<script src="app.js" defer>`
- 블로그의 다른 파일, 다른 앱 파일을 불러 쓰지 않음
- `localStorage` 읽기/쓰기는 모두 `try/catch`, 저장값이 이상하면 버리고 빈 그림으로 시작
- 휴대폰: 좌우 여백 16px, 가로 스크롤 없음, 320px 화면에서도 격자가 잘리지 않음, 그림판에서 손가락으로 끌 때 화면 스크롤 막기, 빠르게 끌어도 칸이 빠지지 않게(이전 칸과 지금 칸 사이를 이어 칠하기)
- PNG: 브라우저 기본 기능(`canvas`)만, 칸마다 정수 크기 사각형으로 칠해 흐려지지 않게, 빈 칸 투명, 체크무늬·격자선 제외
- 화면에 글자를 넣을 때 `innerHTML`에 외부 입력을 넣지 않음 (`textContent`)
- 코드에 한글 주석을 짧게
- 개인 정보·회사 정보·PC 경로를 파일에 넣지 않음 (공개 저장소)
- 그림 데이터 계산(채우기, 되돌리기 기록, PNG용 픽셀 만들기)은 화면 그리기와 분리된 함수로 (Review가 검사하기 쉽게). 2048처럼 Node에서 불러 시험할 수 있게 해 두면 좋음
