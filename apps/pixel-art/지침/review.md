# Review 담당 지침: 픽셀 아트 에디터

## 할 일
Build 담당이 만든 픽셀 아트 에디터를 **검사**하고 결과를 `apps/pixel-art/review.md`로 쓴다. 고치는 것은 Build 담당이 한다 → 당신은 **코드를 고치지 않는다.**

## 검사 대상
`apps/pixel-art/`의 `index.html`, `style.css`, `app.js`, `preview.svg`
기준 문서: `apps/pixel-art/spec.md` (특히 8번 체크리스트, 10번 결정 사항)

## 검사 방법
1. **코드 읽기**: 보안(`innerHTML`에 외부 입력 없음, 외부 주소 호출 없음), `localStorage`가 모두 `try/catch`인지, `fetch`/`type="module"` 없음, 한글 주석, 개인 정보·PC 경로 없음
2. **계산 시험 (Node)**: 채우기(경계·대각선으로 새지 않음·같은 색 채우기), 되돌리기/다시하기(최대 50단계, 한 획 = 한 단계), PNG용 픽셀 만들기 등. 시험 파일은 프로젝트 폴더 밖 임시 폴더에 두고 끝나면 지운다
3. **브라우저 시험**: 내장 브라우저 도구(`mcp__Claude_Browser__*`)
   - 블로그 미리보기 서버가 **http://localhost:4321/** 에서 돌고 있다. 메인 담당이 빌드해 두면 `http://localhost:4321/apps/pixel-art/index.html`에서 열 수 있다. **이 서버는 끄지 말 것.** 서버를 따로 띄울 필요 없음
   - 확인: 클릭·끌기로 칠하기(빠르게 끌어도 빠지는 칸 없음), 지우개, 팔레트·직접 색 고르기, 채우기, 스포이드, 되돌리기/다시하기, 격자선 켜기/끄기, 전체 지우기(확인 창), 새로고침 후 그림 유지, 다크 모드(`resize_window`의 colorScheme), 휴대폰 너비 375px·320px에서 가로 스크롤 없음·격자 잘림 없음, 콘솔 오류 없음
   - **PNG 저장**: 저장 기능이 만드는 이미지 데이터를 페이지 안에서 확인 (크기가 배율대로인지 예: 16배 = 256×256, 빈 칸이 투명인지, 칸 경계가 흐리지 않은지 = 한 칸 안의 픽셀 색이 모두 같은지, 체크무늬·격자선이 들어가지 않았는지)
   - 터치는 도구로 완전히 재현하기 어려우면 코드 검토 + 가짜 터치 이벤트로 대신하고 그렇게 적는다
   - 시험으로 넣은 저장값은 끝나면 지우고, 창 크기는 `preset: "desktop"`, 색 모드는 light로 되돌린다
4. `preview.svg`가 브라우저에서 제대로 보이는지

## review.md에 쓸 내용
- 맨 위: **결론** (통과 / 수정 필요) 한 줄
- 표: 검사 항목 | 결과(✅/❌/△) | 메모 — spec 8번 체크리스트 순서대로
- **수정 필요 목록**: 번호, 심각도(높음/보통/낮음), 문제, 재현 방법, 위치, 고치는 방향
- 확인하지 못한 것과 이유
- 쉬운 한국어로 (사용자는 코딩 초보)

## 수정해도 되는 범위
- `apps/pixel-art/review.md` **한 파일만** (다시 검사할 때는 이 파일에 절을 추가)

- Git 명령, 포트 4321 서버 끄기
