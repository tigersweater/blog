# Build 담당 수정 지침: 새 웹앱 규칙 맞추기 (2048·픽셀 아트 공통)

CLAUDE.md "웹앱 규칙"에 4번(블로그 색상 팔레트 따르기)과 5번(사용법 안내 문구 넣기)이 추가되었다. 두 앱을 이 규칙에 맞춘다.

## 할 일
| 번호 | 앱 | 할 일 |
|---|---|---|
| 1 | 2048, 픽셀 아트 | CSS 변수 이름을 블로그(`src/style.css`)와 같게: `--text-sub` → `--sub`, `--press` → `--pressed`. 선언(기본·다크 모두)과 `var(...)` 쓰는 곳 전부. **값은 바꾸지 않는다** |
| 2 | 픽셀 아트 | `index.html`에 사용법 안내 문구 추가. 화면에서 바로 보이는 곳(제목 아래 설명 근처 또는 그림판 아래)에 짧게. 담을 내용: ① 칸을 누르거나 누른 채 끌어 칠하기(휴대폰은 손가락으로 끌기) ② 채우기 = 같은 색으로 이어진 영역을 한 번에 칠함 ③ 스포이드 = 그림에서 색을 집어 옴. 2~3줄 이내, 보조 글자색(`--sub`), 휴대폰 너비 320px에서도 가로 스크롤 없게. 필요하면 `style.css`에 작은 스타일 추가 |

- 픽셀 아트의 저장 버튼 마우스 올림/누름 색(#0077EB, #006AD1)은 **그대로 둔다** (사용자 결정)
- 숫자 타일 색·팔레트 16색·체크무늬·격자선 색은 앱에 꼭 필요한 색이라 그대로 둔다
