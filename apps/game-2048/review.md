### 8-4. 조작

| 항목 | 결과 | 메모 |
|---|---|---|
| 방향키 4개, WASD(대·소문자) | ✅ | 실제 키 입력으로 ←↑→↓, d, Shift+W, s 확인 |
| 한글 입력 상태 WASD | △ | 코드는 `e.code`(키 자리) 기준이라 동작해야 함. 가짜 이벤트(`key:'ㅁ', code:'KeyA'`)로는 동작 확인. **실제 한글 입력기 상태는 도구로 재현 못 함** |

| 휴대폰 밀기 | △ | 브라우저 안에서 만든 터치 이벤트로 상하좌우 모두 동작, 짧게(10px) 톡 치면 안 움직임, 밀 때 스크롤 막기(`preventDefault`) 확인. **실제 휴대폰 손가락 조작은 확인 못 함**. 게임판에 `touch-action: none`, 두 손가락 무시 코드 있음 |

## 재검사 (수정 확인) — 2026-11-03

Build 담당이 수정 목록 1~3번(색 대비)을 고친 `style.css`·`preview.svg`만 다시 봤다. 블로그 미리보기 서버(`http://localhost:4321/apps/game-2048/index.html`, 빌드된 수정본)에서 확인했다. 받아 온 `style.css`가 고친 원본과 같은 값인지도 확인했다. 시험용 판은 `game2048.state`에 넣어 만들었고, 끝난 뒤 원래 저장값으로 되돌렸다.
