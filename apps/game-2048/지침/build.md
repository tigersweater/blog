# Build 담당 지침: 2048 게임

## 할 일
`apps/game-2048/spec.md`(계획서)대로 2048 게임을 만든다. 계획서 **10번 "결정 사항"**이 최종 결정이다.

## 만들 파일 (이 4개만)
| 파일 | 내용 |
|---|---|
| `apps/game-2048/index.html` | 화면 뼈대 (`<html lang="ko">`, viewport 메타, 제목 "2048") |
| `apps/game-2048/style.css` | 디자인, 다크 모드(`prefers-color-scheme`), 휴대폰 대응, "톡" 효과 |
| `apps/game-2048/game.js` | 게임 규칙, 조작(방향키·WASD·스와이프), 점수, 저장 |
| `apps/game-2048/preview.svg` | 블로그 카드용 미리보기 그림. 게임 화면을 본뜬 4×4 판(타일 몇 개 + "2048" 제목). 가로:세로 = 16:10 정도, 밝은 색 기준, 외부 글꼴 없이 |

## 지켜야 할 규칙
- HTML, CSS, JavaScript만. 프레임워크·외부 라이브러리·CDN·외부 글꼴 쓰지 않음
- `index.html`을 **더블클릭(file://)으로 열어도 동작**: `fetch`, `type="module"`, `import` 쓰지 않음. 스크립트는 `<script src="game.js" defer>`
- 블로그의 다른 파일을 불러 쓰지 않음 (색은 spec.md 5-5를 그대로 CSS에 적음)
- `localStorage` 읽기/쓰기는 모두 `try/catch` (저장이 막혀도 게임 정상 동작). 저장 이름은 spec.md 7번대로
- 휴대폰: 좌우 여백 16px, 가로 스크롤 없음, 게임판에서 밀 때 화면 스크롤 막기(`touch-action: none` 등), 작은 화면(320px)에서도 판이 잘리지 않게
- 화면에 숫자·글자를 넣을 때 `innerHTML`에 외부 입력을 넣지 않음 (`textContent` 사용)
- 코드에 한글 주석을 짧게
- 개인 정보·회사 정보·PC 경로를 파일에 넣지 않음 (공개 저장소)
- 규칙 계산(한 줄 밀기·합치기)은 화면 그리기와 분리된 함수로 (Review가 검사하기 쉽게)

## 수정해도 되는 범위
- 위 4개 파일 **새로 만들기만**

## 하면 안 되는 일
- `spec.md`, `지침/` 폴더, 블로그 파일(`build.mjs`, `src/`, `글/`, `사이트/`, CLAUDE.md 등) 수정
- Git 명령
- 백그라운드 서버 실행을 남겨 두기 (시험용으로 띄웠다면 끝나기 전에 끌 것)

## 완료 기준
- spec.md 2번의 필수 기능 F1~F13과 결정 사항 D1~D5가 모두 동작
- 스스로 간단히 확인: Node로 `game.js`의 합치기 함수를 불러 `2 2 2 2 → 4 4`, `2 2 4 → 4 4`, `4 4 4 → 8 4` 정도 시험 (가능하면). 브라우저 확인은 Review 담당이 따로 함
- 끝나면 한국어로 짧게 보고: 만든 파일, 구현한 기능, 스스로 시험한 결과, 확실하지 않은 점
