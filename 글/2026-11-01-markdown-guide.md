>

## 코드 블록

```js
// 백틱 세 개로 감싸면 코드 블록이 됩니다
function hello(name) {
  return `안녕하세요, ${name}님`;
}
```

### 콜아웃

> [!note] 메모
> 옵시디언의 콜아웃 상자입니다. `> [!note]`로 시작합니다.

> [!tip]
> 제목을 비우면 종류 이름(팁)이 제목이 됩니다.

> [!warning] 주의할 점
> `warning`, `danger`, `example`, `quote` 등도 쓸 수 있습니다.

> [!example]- 눌러서 펼치기
> `[!종류]` 뒤에 `-`를 붙이면 접힌 상태로, `+`를 붙이면 펼친 상태로 시작합니다.

### 숨김 메모

%%이 문장은 블로그에 보이지 않습니다.%%
`%%`로 감싼 글은 옵시디언에서만 보이고 블로그에는 나오지 않습니다. (바로 위 줄에 숨긴 문장이 있습니다)

### 참고

- 제목은 `##`(큰 제목), `###`(작은 제목)을 쓰세요. 맨 위 `#` 제목은 글 제목으로 쓰입니다.
- 큰 제목·작은 제목이 3개 이상이면 글 위에 **목차**가 자동으로 생깁니다.
- 글 안에 HTML 태그(`<b>` 등)를 쓰면 글자 그대로 보입니다. 안전을 위한 규칙입니다.
