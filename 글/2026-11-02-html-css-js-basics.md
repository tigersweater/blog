오늘 프레임워크 없이 HTML, CSS, JavaScript만으로 이 블로그를 만들었습니다. 웹페이지가 무엇으로 이루어져 있는지 정리해 둡니다.

## 한 줄 요약

| 재료 | 하는 일 | 업무에 빗대면 |
|---|---|---|
| **HTML** | 내용과 구조 | 보고서의 **목차와 본문** |
| **CSS** | 모양과 배치 | 보고서의 **서식** (글꼴·색·여백) |
| **JavaScript** | 동작 | 엑셀의 **매크로** (버튼을 누르면 무언가 일어남) |

세 가지는 따로 파일로 나누어 두고 HTML이 나머지 둘을 불러옵니다. 내용·서식·동작을 나눠 두면 하나를 고쳐도 나머지가 흔들리지 않습니다.

## HTML: 내용과 구조

HTML은 글에 **이름표(태그)**를 붙여서 "이건 제목, 이건 문단, 이건 링크"라고 알려 주는 언어입니다.

```html
<h1>오늘의 배움</h1>
<p>Claude Code로 배우고 기록하는 공간</p>
<a href="index.html">글 목록</a>
```

- `<h1>`~`<h6>`: 제목 (숫자가 작을수록 큰 제목)
- `<p>`: 문단
- `<a href="주소">`: 링크
- `<ul>`, `<ol>`, `<li>`: 목록
- `<img src="그림 주소">`: 그림
- 대부분 `<태그>내용</태그>`처럼 **여는 태그와 닫는 태그**가 짝을 이룹니다.

알게 된 점:

- HTML은 모양이 아니라 **의미**를 적는 곳입니다. 글씨를 크게 하고 싶어서 `<h1>`을 쓰는 게 아니라, 제목이라서 `<h1>`을 씁니다. 크기는 CSS가 정합니다.
- 맨 위의 `<meta name="viewport" ...>` 한 줄이 있어야 휴대폰에서 화면이 작게 쪼그라들지 않습니다.

## CSS: 모양과 배치

CSS는 "**어떤 것**을 **어떻게** 꾸밀지" 적는 규칙 목록입니다.

```css
.post-card {
  background: var(--card);
  border: 1px solid var(--border);
  border-radius: 10px;
  padding: 20px 22px;
}
```

- `.post-card`: 꾸밀 대상 (이 이름표가 붙은 요소)
- `{ }` 안: 꾸밀 내용. `속성: 값;` 형태
- `border-radius`: 모서리 둥글게 / `padding`: 안쪽 여백 / `margin`: 바깥 여백

### 색을 변수로 모아 두기

이번에 가장 유용했던 것은 **CSS 변수**입니다. 색을 한곳에 이름 붙여 모아 두고, 여기저기서 이름으로 불러 씁니다.

```css
:root {
  --canvas: #EEEFF2;   /* 바탕 */
  --text: #1D1D1F;     /* 글자 */
}
:root[data-theme="dark"] {
  --canvas: #1A1B1E;
  --text: #ECECEE;
}
body {
  background: var(--canvas);
  color: var(--text);
}
```

엑셀에서 숫자를 셀마다 직접 쓰지 않고 **기준 셀 하나를 참조**하게 해 두는 것과 같습니다. 다크 모드는 이 기준값만 바꿔 끼우면 화면 전체가 한 번에 바뀝니다.

### 화면 크기에 따라 다르게

```css
@media (max-width: 640px) {
  .article { padding: 28px 20px; }
}
```

화면 폭이 640px 이하(휴대폰)일 때만 적용되는 규칙입니다. 같은 HTML로 컴퓨터와 휴대폰 화면을 모두 맞출 수 있습니다.

## JavaScript: 동작

JavaScript는 사용자가 무언가를 했을 때 **화면을 바꾸는** 프로그램입니다. 이 블로그에서는 두 가지에 썼습니다.

1. 달/해 버튼을 누르면 다크 모드로 바뀌기
2. 태그를 누르면 그 태그의 글만 보이기

```js
var btn = document.getElementById('theme-toggle');   // 1. 버튼을 찾고
btn.addEventListener('click', function () {           // 2. 눌렸을 때
  root.setAttribute('data-theme', 'dark');            // 3. 다크 모드 표시를 붙인다
});
```

흐름은 항상 비슷합니다.

1. **찾기**: 화면에서 대상 요소를 찾는다 (`getElementById`, `querySelector`)
2. **기다리기**: 클릭 같은 일이 일어나기를 기다린다 (`addEventListener`)
3. **바꾸기**: 글자·속성·보이기 여부를 바꾼다

JavaScript가 직접 색을 바꾸지 않는다는 점이 재미있었습니다. `data-theme="dark"` 표시만 붙이면, 실제 색 변경은 CSS 변수가 알아서 합니다. **역할 분담**이 잘 되어 있으면 코드가 짧아집니다.

### 선택 기억하기

```js
try { localStorage.setItem('theme', 'dark'); } catch (e) {}
```

`localStorage`는 브라우저 안의 작은 메모장입니다. 고른 모드를 적어 두면 다음에 열어도 그대로입니다. 브라우저 설정에 따라 메모장을 못 쓸 수도 있어서 `try { } catch`로 감싸 두었습니다. 실패해도 화면이 멈추지 않게 하는 안전장치입니다.

## 세 가지가 함께 동작하는 순서

1. 브라우저가 **HTML**을 읽어 내용을 배치한다
2. HTML이 불러온 **CSS**로 모양을 입힌다
3. HTML이 불러온 **JavaScript**가 버튼 등에 동작을 연결한다
4. 사용자가 버튼을 누르면 JavaScript가 표시를 바꾸고 → CSS가 그 표시에 맞춰 모양을 바꾼다

## 덤: 이 블로그는 어떻게 만들어지나

블로그 글은 HTML이 아니라 **마크다운**으로 씁니다. `#`은 제목, `**굵게**`처럼 간단한 기호로 쓰는 글 형식입니다. `빌드.bat`을 누르면 Node.js로 만든 변환 프로그램이 마크다운을 HTML로 바꿔 줍니다.

- 원고(마크다운) → 인쇄소(빌드) → 책자(HTML 블로그)
- 그래서 글을 쓸 때는 HTML 태그를 몰라도 됩니다
